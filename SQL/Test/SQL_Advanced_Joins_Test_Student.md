# SQL Practical Test — Advanced Joins & Business Analysis

## Student Instructions

**Database:** `SQL_Advanced_Joins_Test`  
**Platform:** SQL Server / SSMS  
**Total Questions:** 50  
**Recommended Difficulty:** Medium → High

### Rules

1. Write a separate SQL query for every question.
2. Use only topics covered.
3. Use proper aliases and readable formatting.
4. Queries should return the requested business information, not merely the requested columns.
5. Where a question asks for all records, make sure unmatched records are not accidentally removed.
. Unless a question explicitly asks for a particular JOIN type, choose the JOIN that correctly solves the business requirement.
